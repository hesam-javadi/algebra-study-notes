# جزوهٔ جبر خطی عددی

جزوهٔ تعاملی و ساده‌شده با همهٔ اثبات‌ها. سایت کاملاً ایستا است (HTML، CSS و JavaScript ساده، بدون نیاز به build) و همهٔ فونت‌ها و KaTeX داخل پروژه هستند، پس بدون اینترنت هم کار می‌کند.

## ساختار

| مسیر | محتوا |
|---|---|
| `index.html` | صفحهٔ اول و فهرست فصل‌ها |
| `ch2.html` | فصل ۲: مفاهیم پایه (صفحات ۱۵ تا ۳۰ کتاب) با حل کامل ۱۹ تمرین آخر فصل |
| `ch3.html` | فصل ۳: مسئلهٔ دستگاه معادلات خطی (صفحات ۳۱ تا ۵۶ کتاب) |
| `assets/css/main.css` | طراحی کلی، رنگ‌ها (روشن و تیره)، کادرها، اثبات‌ها، خودآزمایی‌ها |
| `assets/css/widgets.css` | ظاهر ابزارهای تعاملی |
| `assets/js/core.js` | فهرست مطالب، حالت تیره، اثبات گام‌به‌گام، خودآزمایی، علامت «یاد گرفتم» |
| `assets/js/widgets.js` | ابزارهای تعاملی: اجراکنندهٔ حذف گاوسی/گاوس-جردن/LU، آزمایشگاه بدوضعی، نمودار هزینه، ماتریس جایگشت، آزمایشگاه ماتریس، کارت‌های مرور |
| `assets/js/widgets-ch2.js`، `assets/css/widgets-ch2.css` | ابزارهای فصل ۲: گوی واحد نرم‌ها، کوشی-شوارتز، نرم‌های ماتریس ۲×۲، توان‌های ماتریس |
| `assets/fonts/` | فونت وزیرمتن (مجوز OFL) |
| `assets/vendor/katex/` | KaTeX 0.16.11 برای نمایش فرمول‌ها (مجوز MIT) |

## اجرا روی کامپیوتر

به خاطر فونت‌ها بهتر است صفحه را با یک سرور ساده باز کنی، نه با دوبار کلیک روی فایل:

```powershell
python -m http.server 8765
```

بعد در مرورگر برو به `http://localhost:8765`.

## انتشار روی GitHub Pages

1. یک مخزن (repository) در GitHub بساز و همهٔ فایل‌های این پوشه را در شاخهٔ `main` قرار بده.
2. در تنظیمات مخزن: **Settings → Pages**، در بخش *Build and deployment* گزینهٔ **Deploy from a branch** را انتخاب کن، شاخهٔ `main` و پوشهٔ `/ (root)` را بزن و ذخیره کن.
3. بعد از یکی دو دقیقه سایت در آدرس `https://<نام-کاربری>.github.io/<نام-مخزن>/` در دسترس است.

## اضافه کردن فصل بعدی

`ch3.html` را الگو بگیر: هر بخش یک `<section class="sec">` با یک `h2` شناسه‌دار است و فهرست مطالب خودکار ساخته می‌شود. کادرها با کلاس‌های `box def`، `box thm`، `box ex`، `box rem`، `box intu` و `box warn` ساخته می‌شوند و اثبات‌ها با `div.proof` و `li.step` (توضیح «چرا؟» در `div.why`). ابزارهای تعاملی با `<div class="widget" data-widget="..." data-preset="..."></div>` اضافه می‌شوند. در آخر یک کارت در `index.html` اضافه کن.

پیشرفت مطالعه (بخش‌های یادگرفته و جعبه‌های کارت مرور) فقط در همان مرورگر ذخیره می‌شود.
